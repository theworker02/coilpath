# coilpath

Coil HTML/Markdown path fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/coilpath/

## Install / run

```bash
git clone https://github.com/theworker02/coilpath.git
cd coilpath
node src/cli.js
node --test
```
